- 2026-09-24: Direction: an open, query-time rediscovery layer for science ("old idea under a new name"), built for humans and AI scientists, plus the first cross-field rediscovery benchmark and a measurement of the rediscovery rate. Reason: the problem is documented at scale (Gupta and Pruthi 2025: 24% of 50 AI-generated research documents borrowed uncited work; AI-scientist "discoveries" repeatedly turned out to be known results), and no open system checks one claim across several fields' vocabularies with quote-level evidence.
- 2026-09-24: Framed as large as the evidence allows: infrastructure everyone can call, "Similarity Check for ideas". Not framed as "the first detector", because the technical core is published (Kulikowski 2026).
- 2026-09-24: The benchmark is the main defensible contribution; the system is how it gets built and used. Publish the benchmark fast.
- 2026-09-24: Built on Claude Code (subagents, hooks, MCP); Claude Agent SDK for batch evaluation.
